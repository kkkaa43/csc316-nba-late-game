# Data dictionary

All files are produced by `scripts/build_data.py` from ESPN NBA play-by-play (SportsDataverse / hoopR),
2024–25 regular season, 1,230 games. Numbers are written with up to six decimals.

## Shared definitions

| Term | Meaning |
|---|---|
| trailing team | the team behind on the scoreboard **before** the event (ESPN rows store the score after the event, so the previous row's score is used) |
| `deficit` | points behind, binned `1–3`, `4–6`, `7–10`, `11+` (right-closed: 3 → `1–3`, 4 → `4–6`) |
| `time` | minutes left in the fourth quarter, binned `9–12`, `6–9`, `3–6`, `0–3` (right-closed; exactly 3:00 → `0–3`, exactly 6:00 → `3–6`). Overtime is excluded. |
| FGA | field-goal attempt: a shooting play worth 2 or 3 points (free throws excluded) |
| team-game | one team in one game |
| comeback | the trailing team won the game (overtime wins count) |

## `static/data/fingerprint.csv` (charts 1 and 3, the sticky summary bar). 16 rows, one per game state

| Column | Type | Description |
|---|---|---|
| `deficit` | category | deficit band (see above) |
| `time` | category | time window (see above) |
| `shots` | int | FGA by the trailing team |
| `threes` | int | three-point attempts by the trailing team |
| `makes` | int | made field goals by the trailing team |
| `turnovers` | int | turnovers committed by the trailing team (ESPN type ids 62–90 and 206) |
| `fouls` | int | personal-type fouls committed by the trailing team (technicals excluded) |
| `exposure_seconds` | float | game-clock seconds during which some team trailed by this deficit inside this time window |
| `three_share` | float 0–1 | `threes / shots` |
| `shots_per_min` | float | `shots / (exposure_seconds / 60)`: FGA per minute spent trailing |
| `turnovers_per_min` | float | `turnovers / (exposure_seconds / 60)` |
| `fouls_per_min` | float | `fouls / (exposure_seconds / 60)` |
| `state_games` | int | distinct trailing team-games that were ever in this state (counted once per state; a game can appear in several states) |
| `comeback_games` | int | of those, how many the trailing team won |
| `comeback_rate` | float 0–1 | `comeback_games / state_games` |

## `static/data/team_states.csv` (chart 6, H4). 480 rows, team × game state

| Column | Type | Description |
|---|---|---|
| `team` | string | ESPN team abbreviation of the trailing team (e.g. `BOS`, `GS`, `UTAH`) |
| `deficit`, `time` | category | game state |
| `attempts` | int | that team's FGA while trailing in this state |
| `threes` | int | that team's three-point attempts while trailing in this state |
| `makes` | int | that team's made FGA while trailing in this state |

The website sums these rows over the chosen states and computes `threes / attempts` with a Wilson 95% interval.

## `static/data/pace.csv` (chart 5, J2). One row per game with a trailing team at the 5:00 mark (1,197 rows)

| Column | Type | Description |
|---|---|---|
| `game_id` | string | ESPN game id |
| `team` | string | team trailing at 5:00 |
| `opponent` | string | team leading at 5:00 |
| `deficit_at_five` | int | points behind at 5:00 (score after the last event at or before 5:00 left; no look-ahead) |
| `deficit` | category | `deficit_at_five` binned like the other files |
| `prior5_fga` | int | trailing team's FGA from 10:00 to 5:00 left |
| `last5_fga` | int | trailing team's FGA in the final 5:00 (whether or not it still trailed) |
| `change_fga_per_min` | float | `(last5_fga - prior5_fga) / 5` |
| `comeback` | bool (`True`/`False`) | the team trailing at 5:00 won |

Games tied at 5:00 have no trailing team and are left out. The website groups games by
`last5_fga - prior5_fga` into 3+ fewer, 1–2 fewer, same, 1–2 more, 3+ more.

## `static/data/metadata.json`

Provenance for the build: source URL, SHA-256 of the source file, build date, number of games,
excluded games and why, number of Q4 events and trailing-team FGA, row counts, short definitions.

## `data/cleaned/q4_events.csv` (not committed, 11 MB; regenerated by the script, included in the ZIP)

One row per fourth-quarter event after cleaning (149,545 rows).

| Column | Type | Description |
|---|---|---|
| `game_id` | string | ESPN game id |
| `game_play_number` | int | chronological event number within the game |
| `team_abbrev` | string | team credited with the event (blank for neutral events) |
| `period_number` | int | always 4 |
| `seconds_left` | float | seconds left in the quarter |
| `home_before`, `away_before` | int | score before the event |
| `home_score`, `away_score` | int | score after the event |
| `deficit_before` | float | points the event's team trailed by before it (negative = leading; blank for neutral events) |
| `is_fga`, `is_three`, `is_made` | bool | field-goal attempt, three-point attempt, made field goal |
| `is_turnover`, `is_foul` | bool | turnover, personal-type foul |
| `winner_id` | int | ESPN team id of the game's winner |
