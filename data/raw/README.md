# Raw input

`scripts/build_data.py --season 2025` downloads the source parquet here once and reuses it:
https://github.com/sportsdataverse/sportsdataverse-data/releases/download/espn_nba_pbp/play_by_play_2025.parquet
(about 21 MB, not committed). Its SHA-256 is recorded in `static/data/metadata.json`.
